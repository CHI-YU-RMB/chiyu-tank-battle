# ⚔ 坦克大战 (Battle City)

一个用纯 HTML + Canvas + JavaScript 实现的经典坦克大战小游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 🎮 玩法

- **方向键 / WASD** —— 移动坦克
- **空格键** —— 开火
- **P** —— 暂停 / 继续
- **M** —— 开关声音

## 🛡 目标

守住屏幕底部的基地（鹰），消灭每一关的所有敌方坦克。基地被摧毁或生命耗尽则游戏结束。

## ✨ 特色

- 经典的地图元素：**砖墙**（可摧毁）、**铁墙**（不可摧毁）、**基地**
- 三种敌人：普通、快速、重型（重型需 3 发炮弹）
- 随机掉落道具：
  - ★ **星星** —— 升级火力（满级可击穿铁墙）
  - ➕ **生命** —— 增加一条命
  - 💣 **炸弹** —— 消灭场上所有敌人
- 多个关卡，难度逐关提升
- 像素爆炸特效与复古音效

## 🚀 运行

直接用浏览器打开 `index.html`，或部署到 GitHub Pages：

1. 仓库 **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`
3. 分支选择 `main`，目录 `/ (root)`，保存即可

## 📁 文件

- `index.html` —— 游戏全部代码（HTML + CSS + JS）
